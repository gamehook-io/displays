# Overlay author boundary

Edit this folder and add assets under `src/pokemon/public/assets/` (reference them as `assets/file.png`) for overlay design. Import shared components and hooks from `@overlay`. Keep framework network code in `src/shared/`. Use actual mapper property paths. Read live values in JSX expressions or accessor functions. Keep the document background transparent. The game opening is filled by default (`fillOpening`); the game capture sits above the overlay in OBS. Demo data must remain an explicit `?demo=1` choice. Do not embed an emulator or game capture.
